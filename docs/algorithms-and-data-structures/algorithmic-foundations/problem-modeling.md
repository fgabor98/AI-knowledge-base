# Problem Modeling

Scaffold for turning an informal problem into inputs, outputs, constraints, assumptions, and testable behavior.

## Coverage

- problem statements
- input and output descriptions
- preconditions and postconditions
- edge cases
- constraints and bounds

## Programming Examples

- C: add the primary implementation example, with bounds, error handling, and memory behavior visible.
- Python: add a reference implementation when it helps explain the algorithm, generate test cases, or compare behavior.

## Embedded And Systems Angle

- make resource limits explicit before choosing an algorithm
- separate hardware facts from software policy
- treat invalid input and partial data as normal cases to model

## Future Material

- worked examples from buffers, logs, device state, and configuration data
- checklist for converting requirements into an algorithm contract
- exercises that expose missing constraints
